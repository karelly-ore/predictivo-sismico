## Tecnologías y Herramientas Utilizadas
* **Lenguaje Core:** Python 3.x
* **Análisis y Procesamiento de Datos (ETL):** Pandas, NumPy (Lectura y limpieza de catálogos en formato Excel).
* **Machine Learning:** Scikit-Learn (Modelo implementado: **Random Forest Classifier**)
* **Visualización Geográfica:** Generación de mapas interactivos en HTML usando Python (Módulo de mapas).
* **Control de Versiones:** Git / GitHub
* **Arquitectura:** Código modularizado (limpieza, análisis espacial, entrenamiento del modelo y visualización).
